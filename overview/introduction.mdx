## What is the IOX Platform?

The IOX Platform is a **Cost Intelligence Suite** for construction projects. It brings together cost planning, procurement, contract management, document control, and parametric cost modelling into a single, integrated system — all running against a common, governed data layer.

Rather than a collection of disconnected tools, the IOX Platform is designed as a coherent whole. Every module shares the same foundational data — the same projects, contracts, organisations, and users — with no duplication and no synchronisation overhead.

## How it is structured

The platform is built in two layers.

<CardGroup cols={2}>
  <Card title="IOX Core" icon="database" color="#142845">
    The shared data foundation. IOX Core defines and owns the canonical data for every concept that is shared across the platform — identity, organisations, projects, contracts, documents, cost plans, procurement, and more.

    Every module reads from and writes to IOX Core. There is one version of the truth.
  </Card>
  <Card title="Modules" icon="puzzle-piece" color="#8FB6DE">
    Specialist applications built on top of IOX Core. Each module adds domain-specific capability — parametric cost modelling, for example — without duplicating shared data.

    Modules reference IOX Core entities directly. They extend the platform; they do not replicate it.
  </Card>
</CardGroup>

## What this documentation covers

This site is the canonical reference for the IOX Platform data architecture. It covers:

- **Platform architecture** — how IOX Core and modules fit together, and the governing rules for the shared data layer
- **IOX Core** — all 12 functional segments, their entities, attributes, relationships, and the decisions that shaped them
- **ParametriX** — the parametric cost modelling module: its entities, its integration with IOX Core, and the calculation model
- **Governance** — how the data model is versioned, how changes are proposed and approved, and how the audit trail is maintained
