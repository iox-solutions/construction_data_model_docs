### IOX Core entities used by ParametriX

ParametriX references four IOX Core entities directly. It does not duplicate any of them.

| IOX Core Entity | How ParametriX uses it |
|---|---|
| User | Every Masterplan records who created it |
| Contract | Every Masterplan belongs to exactly one Contract |
| BenchmarkProject | A Masterplan may optionally reference a benchmark for comparison |
| AuditLog | All ParametriX activity is captured in the shared platform audit trail |
